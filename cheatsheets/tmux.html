Keybinding reference for your config. Almost everything starts with the prefix, then a key. Stock tmux bindings you didn't remap still work — this card lists the useful ones alongside your customizations. Source: ~/.tmux.conf

Prefix
Ctrl+Space
remapped from Ctrl+b · press twice to send it through
● your customization ○ tmux default ◆ from a plugin ▲ changed from stock (see gotchas) prefix = Ctrl + Space

Essentials

○prefix?List every key binding (the live cheat sheet)
●prefixrReload ~/.tmux.conf
○prefix:Command prompt
○prefixdDetach session (leave it running)
○prefixtBig clock

Panes · split — keeps current dir

●prefixvSplit left | right (v = vertical divider)
●prefixsSplit top / bottom (s = stacked)
○prefix%Stock split left | right (also works)
○prefix"Stock split top / bottom (also works)

Panes · move & size

●prefixhjklFocus pane left / down / up / right (vim keys)
●prefix←↓↑→Resize by 5 — hold to repeat
○prefixzZoom pane fullscreen / restore
○prefixoCycle to next pane
○prefix;Jump to last-used pane
○prefixqFlash pane numbers — press one to jump

Panes · manage

○prefixxKill pane (asks y/n)
○prefix{}Move pane earlier / later in layout
○prefixSpaceCycle preset layouts
○prefix!Break pane out into its own window

Windows — numbered from 1

●prefixcNew window (keeps current dir)
○prefixnpNext / previous window
○prefix1…9Jump to window by number
○prefixwTree of windows & sessions
○prefix,Rename window (auto-named to dir otherwise)
○prefix&Kill window (asks y/n)

Sessions

○prefixwChoose session/window (use this — see gotchas)
○prefix$Rename session
○prefix()Previous / next session
○prefixdDetach

Copy mode · navigate — vi keys

●prefixEnterEnter copy mode (or prefix [)
○hjklMove — or arrow keys
○wbWord forward / back
○gGTop / bottom of buffer
○/?Search down / up
○nNNext / previous match
○qQuit copy mode

Copy mode · copy & paste

●vBegin selection
●yCopy selection → macOS clipboard (pbcopy) & exit
○SpaceBegin selection (stock vi)
○prefix]Paste most recent copy
○prefix=Choose from buffer list to paste

Mouse — enabled

●ClickFocus a pane, or a window in the status bar
●DragOn a border → resize the pane
●ScrollOver a pane → enter copy mode & scroll history
●SelectDrag to select → auto-copies on release (pbcopy)

Save & restore — resurrect plugin

◆prefixCtrl+sSave all sessions, windows & panes to disk
◆prefixCtrl+rRestore the last saved layout
◆prefixItpm: install plugins listed in the config
◆prefixUtpm: update plugins
◆prefixAlt+utpm: remove plugins not in the config

Gotchas — changed from stock tmux

▲prefixIs Ctrl + Space, not Ctrl+b
▲prefixlFocuses pane right — not last-window. Use n/p
▲prefixsSplits panes — not session tree. Use prefix w
▲prefix←↓↑→Resizes panes — not focus. Use h j k l
▲idxWindows & panes start at 1; gaps renumber on close
